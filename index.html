Ce que fait ce package

Intégration Laravel de l'API Bytez : chat, texte, image, vidéo, audio et multimodal, avec cache et nouvelles tentatives.

Facade et injection

Utilise Bytez::chat(...) ou injecte le service.

Compatible OpenAI

Chat completions et text completions au format OpenAI.

Tous types de modèles

Chat, image, vidéo, audio, multimodal.

Builder

Construction fluide des requêtes.

Cache et retry

Mise en cache et nouvelles tentatives intégrées.

Modèles fermés

Clés de fournisseur possibles pour les modèles propriétaires.

Installation

Le package n'est pas encore publié sur Packagist : on l'installe depuis le dépôt GitHub.

  1. Ajoute le dépôt et installe le package :
    composer config repositories.bytez-laravel vcs https://github.com/martin-lechene/bytez-laravel
composer require martin-lechene/laravel-bytez:dev-main
  2. Ensuite :
    php artisan vendor:publish --tag=bytez-config
  3. Ensuite :
    # .env
BYTEZ_API_KEY=ta-cle

Exemple

use Bytez\LaravelBytez\Facades\Bytez;

$response = Bytez::chat('openai-community/gpt-2')
    ->message('Hello, how are you?');
